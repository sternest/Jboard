# Jboard

Jboard is a collaborative visual idea board. Android is the first target; a web/PWA client is planned.

## Product direction
- Boards with movable sticky notes
- Red connecting threads between ideas
- Attachments: PDFs, images, videos, and other files
- Invite collaborators to projects/boards
- Manual save and activity/history log
- Black and yellow interface, restrained pink accents
- Yellow/pink J emblem and subtle butterfly watermark

## Repository
This repository will contain the Android client and build automation. The web/PWA client and shared backend are planned as separate modules so both clients can share board data.

## Build
The Android project is being scaffolded. APK builds will be produced through GitHub Actions once the Gradle project is complete.
