# Jboard product scope

## Core
- Create and open boards
- Add, edit, move, and delete sticky notes
- Connect notes with red relationship threads
- Manual save
- Board activity history
- Collaborator invitation and shared access
- Upload and attach files (PDF, images, video, other files)

## Visual direction
- Primary: black/charcoal and yellow
- Accent: pink, used selectively
- Connections: red
- Branding: yellow/pink J emblem
- Background: subtle butterfly watermark
- Responsive, clean, approachable workspace

## Architecture direction
Android-first client, with a future web/PWA client and shared backend. Authentication, storage, permissions, collaboration, and synchronization require a backend before multi-user features can be production-ready.

## Prototype boundaries
The initial APK should be a local prototype. It must not imply cloud collaboration, invitations, remote file storage, or cross-device sync are working until a backend is integrated.
